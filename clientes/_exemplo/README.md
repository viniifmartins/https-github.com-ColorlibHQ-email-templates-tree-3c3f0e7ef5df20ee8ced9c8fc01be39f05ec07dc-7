# _exemplo — modelo de pasta de cliente

Copie esta pasta e renomeie para o slug do cliente (`padaria-do-ze`).

```
00-descoberta/  perguntas.md, respostas.md, briefing.md
01-marca/       dna-marca.md, logo.md, identidade-visual.md
02-projeto/     escopo.md, aditivo-NN.md
03-criacao/     copy/, imagens/, posts/
04-web/         arquitetura.md, seo.md, dev.md, performance.md, seguranca.md
05-conteudo/    calendario-<mes>.md
06-midia/       analytics.md, trafego.md
relatorios/     <AAAA-MM-DD>.md — o que foi enviado ao cliente
status.md       painel do gerente de contas (raiz da pasta)
```
